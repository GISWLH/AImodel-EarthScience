# GrainLens Texture to Grain Size Curves

[Open on Kaggle](https://www.kaggle.com/code/giswlh/grainlens-texture-to-grain-size-curves) · [Download ipynb](grainlens-texture-to-grain-size-curves.ipynb)

A camera-aware physical-texture baseline that turns soil photographs into valid grain-size distributions. Includes sample-grouped and cross-camera evaluation.

Run the notebook with the corresponding competition input attached. CPU is sufficient. It contains method code, visual explanations and real-data checks; any optional training-data dependency is explained in its own section. Code by giswlh / Longhao Wang, with AI assistance. Credits and data rights are recorded in the notebook. Competition data and private checkpoints are not distributed.
